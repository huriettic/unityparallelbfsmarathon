# Unity parallel BFS Marathon



Run a parallel breadth first search on a Marathon level.



This uses the Unity job system to run a BFS in parallel.



Load the scene for the BFS object to show options.



Change the name to the .sceA file you want in the folder.



Change the level number if the .sceA file has more than one level in it.



Change the root node to a number within the total number of nodes.



The job completed number will show how many jobs were completed.
